Developer

Attendance OCR is independently developed by Saif Alotaibi to reduce repetitive attendance entry for course staff.

Support and privacy questions: saifmkhalotaibi@gmail.com.

What has been checked

The version 2.1 source update passed 62 automated tests. These cover saving logic, conflicting bins, retries, recovery data, configuration restoration and memory-based storage paths. Automated tests do not replace testing the Windows installer and real Google sign-in, file selection and saving.

Try it with fictional records first

  1. Use a test Google Sheet and attendance PDF containing fictional names.
  2. Sign in, select the sheet and PDF, confirm several names and verify the results.
  3. Try conflicting bins for one student and confirm the other students still save.
  4. Wait for all saving to finish, close the app, reopen it and check resume.

Use the user guide for setup. The current build expects its existing two class-tab labels, shown in the app’s setup reminder. Public names were removed from this website; this does not change the app’s required labels.

Access and release status

Google approval is not claimed here. Sign-in availability depends on the app’s Google publishing status and your organization’s policies. Contact the coordinator for the current installer and access arrangements.

Report a problem

Send the app version, the action you were taking and the error text. Remove student names and other private data from screenshots. Never send passwords, tokens or Google configuration files.
